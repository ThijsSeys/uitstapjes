# Uitstapjes

Web-app met elke week leuke weekenduitstapjes voor gezinnen met jonge kinderen, binnen 1u rijden van Oostrozebeke.

- **Op je gsm zetten:** open de site en kies *Toevoegen aan startscherm* (Android) of *Zet op beginscherm* (iPhone).
- **Je kinderen:** geef in het tabblad *Gezin* hun geboortedatum in. Dat blijft alleen op je eigen gsm.
- **Bronnen:** UiTinVlaanderen en een AI-zoektocht op het web. Kijk voor vertrek altijd op de website van de activiteit.
- **Foto's:** Wikimedia Commons, met de fotograaf en licentie bij elke foto.

De site staat in de map `docs/`. Die wordt gebouwd uit `src/` met `build.ps1`.
